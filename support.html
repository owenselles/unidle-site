Unidle

Support

Unidle keeps your Mac from reporting itself as idle, so it doesn't dim, sleep, or mark itself inactive while you're still at your desk.

Setting up

Unidle needs Accessibility access before it can do anything. macOS requires this permission for any app that signals input activity.

App Store version

Apps from the Mac App Store run in a sandbox, and macOS does not show the Accessibility prompt for sandboxed apps. You'll need to add Unidle to the list yourself:

  1. Open System Settings → Privacy & Security → Accessibility
  2. Click the + button below the list
  3. Choose Unidle from your Applications folder
  4. Make sure its switch is turned on

Unidle's welcome window has buttons that open the right settings pane and reveal the app in Finder, so you can drag it straight in.

Direct download version

The version downloaded from this site will show the standard macOS permission prompt. Click Grant Access in the welcome window and approve it.

Using it

  • Keep Me Active — the main switch, in the menu bar
  • Only During Work Hours — restricts it to the days and times you set, including overnight shifts
  • Step in after — how long a pause should last before Unidle acts. Shorter is safer if an app marks you away quickly.
  • Launch at login — starts Unidle automatically

Troubleshooting

The menu says "Needs Accessibility access"

The permission hasn't been granted, or it was reset. Follow the setup steps above. If Unidle already appears in the Accessibility list, try removing it with the − button and adding it again — macOS ties the permission to the app's exact location, so moving the app can invalidate it.

It says Active, but an app still marks me away

Lower the Step in after value. Some apps mark you away after only a few minutes, and the setting needs to be shorter than that.

My Mac still goes to sleep

Check that Keep Me Active is on, and that you're inside your work-hours window if scheduling is enabled. The menu shows the current status and idle time.

I don't see the menu bar icon

If your menu bar is full, or you use a menu bar manager, the icon may be hidden. macOS hides overflow items on Macs with a notch.
